## 保留的目录约定

```text
<workspace>/.dsh-workflow/runs/<runId>/
```

- `workspace`：该 Run 已绑定的工作区路径，不根据当前命令 cwd 重新猜测，也不改为用户目录或自动推断的 Git 根。
- `runId`：插件已有的完整 Run ID，直接作为目录名；不另外生成时间戳、标题 slug 或第二套运行编号。
- 同一 Run 的恢复、重试沿用同一目录；新 Run 使用自己的 Run ID。
- 目录用于该 Run 实际需要的本地报告、证据和临时材料；按需创建，不预建空报告，不要求每次运行生成 run.md。
- 原本应写 Issue/PR 或提交到 Git 的项目文档保持原归属；本地运行材料须忽略且未跟踪，不自动取消跟踪、清理或覆盖用户文件。
- 旧 Run 和旧目录不自动迁移；插件现有 SQLite、trace 位置不变。
