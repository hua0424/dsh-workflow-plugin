# 命名节点结果与显式流程返回

状态：accepted（2026-09-17），待实施。依据用户 Q1–Q6 决策，规格见 `docs/specs/named-results-and-workflow-returns.md`。

以单一命名 result 代替 completed/failed 的业务分支职责；每个结果具有互斥验收条件，Judge 只核验共同条件及所选结果，技术信息缺口保持 NEED_CONTEXT/BLOCK。Child 使用声明返回集合及调用方的完整映射，Root 将业务返回与生命周期分开。这样消除 failed 同时表示返工、穷尽和取消的歧义，避免 outcome+exit 的重复分类、优先级路由及隐式返回传播。

采用停机一次切换：先结束旧 Run，再显式备份旧状态库并初始化新库。不保留 v2 运行时和旧历史查询，不自动迁移/改写冻结快照；旧历史离线保留。该选择以升级窗口和离线历史查询换取单协议实现。实际工作流配置迁移单独建关联 Issue；真实状态库操作和部署不属于本次立项执行。
